## 3. 进实现前必须关闭（P1 硬项）

1. **移动端 44px 与停止确认**（`390-identity.png`、`390-run.png`、`390-inspector.png`）：
   保存约 78×26、停止约 24px、范围约 28px、tabs 约 32px；“需确认”只是灰字，不是确认步骤。所有关键操作 ≥44px；停止运行必须确认 Sheet 或两步内联确认；底部 bar 重排，避免 24px 按钮挤在一起。
2. **字号层级与对比度地板**（`1440-identity.png`、`1440-bot.png`、`1440-run.png`）：
   节标题仍 24–26px，与 H1 32 只差 6–8px；仍有 10px 中文；面包屑 3.7:1、次级导航 3.1:1、未保存琥珀 4.3:1。节标题压到 18–20；清 10px 中文（≥11）；未达标文字提到 ≥4.5:1。
3. **琥珀/风险 token 分离**（`1440-identity.png`、`390-identity.png`、`1440-bot.png`）：
   琥珀同时表示未保存/待办/敏感/收窄/高危范围；桌面“敏感”中性、移动“敏感”琥珀。“收窄”与“未保存”同色；高危“本团队”红框像报错。固定：琥珀只给未保存/待办；风险用常规中性→敏感琥珀→高危红；“收窄”独立状态色或灰+文案；高危范围改“需确认”标签/二次确认；区分“我的待办”与“本页未保存”。
4. **当前用户与登记人统一**（`1440-identity.png`、`1024-identity.png`、`768-run.png`、`390-run.png`）：
   同一套图右上头像在“王/李”之间切换；身份页“登记：李娜”与右上“王”冲突。统一登录人；若“登记”是记录归属，改“记录人/以王强身份保存”，所有 breakpoint 同头像同签名。
5. **Bot 页能力命名与编辑 affordance**（`1440-bot.png`）：
   同一能力三套中文名（查看会话/读取会话/继续会话），左右行不对齐；右侧缺“共享会话/调用 Bot”；“允许/收窄”像静态 badge，但页面有“3 项未保存/保存 3 项”，看不到编辑入口。统一 capability id/中文名，左右严格对齐；工作范围用带 chevron 的 select 或显式“编辑范围”；“本次变更”只做 diff。
6. **1024 双列表/双搜索/角色词**（`1024-identity.png`）：
   左栏账号列表 + 主表账号列表重复，两个搜索，李娜两边同时选中；左栏没有 detail；同一行左“部署管理员”/表“超级管理员”。改 master-detail 或全宽表；只留一个搜索；明确角色与权限组字段。
