## 1. 这次设计要解决什么

Owner 反馈旧界面不满意，要求「用 OpenDesign 好好做」，不是把旧设置页换皮。因此本项目先做方向探索，再做推荐方向的完成稿：

- **三个真正不同的方向**：A 控制台（左栏 + 列表/详情 + 页签，baseline）、B 账簿（章节带 + 页边 + 纸面带 + 签记，推荐）、C 任务简报（待办 + 运行 + 名册，挑战者）。
- **一个 seed 挑战者**：D 索引表单（外部种子图案，只做 divergence probe，不进入实现）。
- **同一批关键页面并排比较**：身份/权限、员工/Bot、团队/运行。
- **推荐 B 的完成稿**：同一批页面在账簿结构下的真实密度与状态。
- **五态与移动端**：加载/空/错/权限不足/成功；375/390 的章节选择 + 摘要卡 + 时间线。

## 3. 推荐方向 B · 账簿

### 3.1 结构

```
章节带 56：01 工作区 · 02 员工 · 03 团队 · 04 身份 · 05 记录 · 待办 · 实时 · 搜索 · 设置齿轮 · 头像
页边 226：对象名 / 一句话 / 关键事实 / 章节索引 01–05 / 主操作 / 切换 / 账本编号
身份例外：280 常驻索引列（账号默认 / 权限组子页）+ 纸面；不做 drill-in
纸面 max 1040：带头（编号 + 标题 + 分隔 + 计数/搜索）→ 带（域）→ 行 → 本次变更 → 签记条
```

- 章节点进去先看到**对象索引**（一张账页），再点进**对象页**；页边有「切换」搜索，补足 drill-in 成本。身份是高频例外：280 常驻索引列，账号默认。
- 对象页的章节索引用页边，不用页签；纸面只显示当前章节。
- 不铺卡片、不做纸张纹理、不做拟物印章；账簿是结构隐喻。

### 3.2 记忆点

- **页边/身份索引 + 签记条**：长页滚动时始终知道「这是谁、几个人、改了几项、谁在改」；保存时出现署名、影响人数、生效时机。
- 琥珀只表示「未保存 / 待处理 / 待签」，不是装饰色。

### 3.3 三尺寸

| 尺寸 | 行为 |
|---|---|
| Desktop ≥1280 | 章节带 + 页边 226 + 纸面 1040；身份 280 索引 + 820 四列表；签记条固定在纸面底部 |
| Pad 768–1279 | 页边折叠为纸面上方的对象摘要带；章节带横向滚动；身份 260 索引 + 四列表；运行泳道 + 底部检查器入口 |
| Mobile 375–767 | 章节选择器 + 摘要卡 + 单列纸面；身份「账号 / 权限组」segmented；权限域折叠；运行时间线 + 底部检查器 Sheet；停止描边 + 确认 |

## 4. 关键页面

### 4.1 身份 / 权限组

- 左侧 280 索引列：内置组与自定义组；顶部「账号 / 权限组」segmented（权限组选中）；底部「新建权限组」。
- 纸面头部：客服组（唯一 H1 30–32）+ 自定义/8 位成员 + 一句说明 + 8 位 / 7 项 / 3 项未保存 / 最近修改 + 另存为副本。
- 能力表：四列（能力 / 风险 / KEY / 范围），单一「范围」列头，32px 范围印章，风险徽章紧跟能力名，表宽 820。
- 本次变更 3 行（旧值 → 新值）；影响 8 位成员的下一次操作。
- 签记条：李娜 · 团队管理员；保存后写入 05 记录；「保存并签记」是脏状态唯一实心主按钮。
- 状态：范围超上限的选项禁用并写原因；内置组只读；未授予用虚线印章；琥珀只表示未保存。

### 4.2 员工 / Bot

- 页边：客服一号（唯一 H1 30–32）、文本 · qwen3.8-flash、归属李娜、人设客服专员、最近活动、状态可用；干净状态「试跑」主，脏状态「保存」主、试跑描边。
- 纸面：账号上限（8 项，两列）| 工作范围（允许/收窄）；有效能力 5 行（可用 / 收窄 / 账号没有），计数与行数一致；本次变更 3 行。
- 规则：Bot 只能做账号能做且工作范围允许的事；人设不授予能力；一屏一个实心主按钮，脏状态给保存。

### 4.3 团队 / 运行

- 页边：客服团队、运行 #128、Mission 一句、队长/成员/用时/成本/发起、状态运行中、1 个失败；主操作「停止运行」。
- 纸面顶部：失败横条（14:35:18 · 缺「调用 Bot」· 王强可授予 + 查看原因）。
- 泳道（客服一号 / 订单查询 / 退款专员 / 知识库 / 售后升级）：左侧父级轨道/深度，跨泳道正交调用边，创建虚线，拒绝红虚线；失败条 24px + 整行 4% 红底；30s 网格、轴 11px。
- 检查器默认选中失败节点；拒绝告警置顶（时间/缺什么/找谁）；工具未执行；权限 bot.invoke 拒绝；「查看记录」主、打开会话禁用。
- 「图」是同一账本的拓扑投影，不是第二真源。

## 5. 五态（跨方向）

| 状态 | 账号列表示例 | 动作 |
|---|---|---|
| 加载 | 6 行骨架，列宽稳定 | 主按钮 loading + 禁用 |
| 空 | 「还没有人加入这台部署。先建一个账号，再决定他能看到什么。」 | 新建账号 / 先建权限组 |
| 错 | 「没能读到账号列表。服务暂时没有响应。稍后重试；一直失败就把编号 k-7f31 给管理员。」 | 重试 / 复制编号 |
| 权限不足 | 「你没有查看账号的权限。需要「查看账号」能力。找这台部署的管理员，把你的账号加入有该能力的权限组。」 | 复制申请说明 / 返回工作区 |
| 成功 | 列表 + 状态 + 下一步「打开某人 / 新建账号」 | 行点击进对象页 |

另两组页面级五态：**权限矩阵**（骨架 / 无能力 / 保存失败 / 只读 / 3 项未保存 + 签记）与**运行**（轴骨架 / 未跑过 / 断线 / 结构可见会话不可见 / 失败前置）。移动端在 390 帧展示成功、失败、检查器 Sheet。

## 6. 设计语言

- 组件：shadcn/ui 官方件（经 `web/src/ui/kit/` 收编）；不手写仿制。
- 令牌：`web/theme.json` Keel Zai Dark；`background #161616`、`panel #202020`、`card #2b2b2b`、`foreground #d4d4d4`、`primary #ffffff`；琥珀用 warning/mark 家族。
- 图标：lucide 单色线性，24×24，1.8pt；不引彩色第三方图标。
- 材质：solid-glass 只用于浮层、粘性条、选中态；不做发光、渐变按钮、玻璃叠玻璃。
- 字号地板：对象 30–32（唯一 H1）/ 节 18–20 / 正文 14 / 元数据 12 / mono key 11；禁止 9px 中文；非 disabled 文本 ≥4.5:1。
- 主操作：脏状态保存为唯一实心主按钮，试跑次之；移动端停止描边 + 确认。
- 琥珀只表示未保存/待办/待签；风险用独立黄→红刻度；范围提升/新增用信息蓝。
- 设置齿轮常驻；记录/审计/变更记录用词统一：章节「记录」、节「变更记录」、能力「查看记录」。
- 间距：4px 阶梯；纸面左右 30–32；带间距 10–14；页边 22。
- 动效：120/180/260ms，只做状态反馈与空间连续性。

## 7. 评审点

4. 索引形态：drill-in + 页边切换，还是常驻索引列。
5. 是否吸收 C 的「待我处理」为顶部窄带。
