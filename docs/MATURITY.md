# Keel 成熟度标准（Definition of Done）

> 目的：把「做到什么程度算好」变成可核对的闸门，避免「功能看起来有了」但没有证据。
> 每个能力（capability）都按 G0–G5 六级评估；**GA = 全部能力达到 G5**。

## 六级闸门

| 闸门 | 名称 | 必须提供的证据 |
|---|---|---|
| **G0** | 规格 | OpenSpec spec（含场景）、公开 Go 接口、配置/线格式 schema、版本号 |
| **G1** | 单机功能 | fake provider 下端到端可用；单测 + 集成测试；错误路径有明确返回 |
| **G2** | 崩溃一致 | 每个 await 点 `kill -9` 注入；不丢事件、不重复可见消息；at-least-once 语义写入文档；恢复测试进 CI |
| **G3** | 可观测 | 每次 run 一条 `run.finished`；Prometheus 指标固定基数；结构化日志含 request/tenant/session/run id；无敏感内容 |
| **G4** | PI 对齐 | PI 录制的事件流回放一致；`AgentTool` 形状一致；真实 SKILL.md / MCP server / hook 配置**零代码改动**可用；`docs/PI-PARITY.md` 的 conformance suite 全绿 |
| **G5** | 规模与运维 | 2GB / 1000 会话 / 64 并发 run；10 分钟随机 kill 混沌；排水/就绪；文档 + 示例 + 安全评审 |

**Beta = G0–G3；Alpha = G0–G1。** 任何能力不得跳级声明；G2 未过不算「可恢复」，G3 未过不算「可运维」。

## GA 的定义

全部六项能力（§能力矩阵）达到 G5，且以下全局条件同时成立：

1. **规模**：2GB cgroup 内 1000 条 SSE + 64 并发 run + 周期 1MiB 图片，RSS 峰值 < 1.8GB，0 OOM。
2. **混沌**：10 分钟随机 SIGKILL（平均 30s 一次），0 丢失事件、0 重复最终回复、run 状态最终收敛。
3. **可观测**：任一 run 可在日志/指标中还原「模型→工具→压缩→结束」全链路；指标 series 数不随会话数增长。
4. **PI 对齐**：事件名/顺序、工具接口、SKILL.md、MCP 配置/命名/传输、压缩与遥测语义与 PI 一致；用真实上游产物验证。
5. **安全**：日志无密钥/消息正文；MCP 凭据脱敏；skill 不能未经许可执行任意代码；tool 拒绝钩子真实生效。
6. **文档**：每个能力有 spec + 示例 + runbook；公开 API 标记 v1 并承诺兼容策略。

## 能力矩阵（当前 → 目标）

| 能力 | 当前 | 目标 | 主要缺口 |
|---|---|---|---|
| 智能体执行 | G1（fake 可跑） | G5 | G2 混沌、G3 遥测、G4 生态、G5 规模 |
| 可恢复性 | G1（模型/工具 kill 各一例） | G5 | generation 幂等、task 状态机、checkpoint 回放、10min 混沌 |
| 上下文压缩 | G0（代码在，未接线） | G5 | 压缩事件/checkpoint 投影、手动压缩、token 账 |
| 可观测 | G0 | G5 | run.finished、指标、日志字段、trace 可选 |
| Skills | G0 | G5 | SKILL.md 加载、渐进披露、租户隔离、权限 |
| MCP | G0 | G5 | 客户端/传输/命名空间/重连/鉴权 |
| Hooks | G0 | G5 | 事件模型、命令钩子、决策语义、审计 |
| 租户/配额 | G1（tenant_id） | G5 | API key、RLS、配额、用量 |
| Provider 文件 | G0 | G5 | blobId、能力位、adapter、缓存 |
| 运维 | G1（health） | G5 | ready、metrics、CI、镜像、排水 |

## 每个闸门的执行方式

- **G0**：合并 spec 前必须能回答「失败时返回什么」「并发时谁赢」「重启后看到什么」。
- **G1**：测试必须能在无网络、无真实模型的情况下跑完（fake provider + mock server）。
- **G2**：崩溃注入不是「跑一次看看」，而是固定矩阵（模型流/工具/追加/压缩/SSE），每格一个测试，进 CI。
- **G3**：任何新指标必须说明基数上界；禁止 session/run id 作为标签。
- **G4**：兼容性用**真实上游产物**验证（真实 SKILL.md、真实 MCP server、真实 hook 配置），不用自造样例。
- **G5**：规模与混沌报告必须附 HTML + 公网链接；数据不可复现时标注环境差异。

## 非目标（本阶段明确不做）

- 不做多节点一致性协议（依赖 PG 单主；多副本靠无状态 + 租约）。
- 不做每租户独立数据库/进程。
- 不做内置工作流编排器（Temporal 式 DAG）；run 是单会话状态机。
- 不做模型训练/微调；只做调用与路由。
- 不在 schema 存价格；只做客观计量。
- 不追求与 pi 代码级同构；只对齐**行为契约**与**产物格式**。
