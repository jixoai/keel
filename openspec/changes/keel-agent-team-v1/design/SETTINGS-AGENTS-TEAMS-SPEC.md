## 2. 两级结构与导航

### 2.1 第一级：设置分区页签

- 页签固定两项，顺序不可变：`Agents`、`团队`。
- 页签右侧带数量徽标：Agents 数量 / 团队数量；使用等宽数字。
- 激活态：文字 `--ink-1`，底部 2px 暖白下划线；非激活态 `--ink-3`。
- 页签可点击切换；键盘 `←` / `→` 在两项间循环，并同步切换页面。
- 切换页签时各自保留自己的五态选择；切走再切回不会重置。
- 页签上方保留全局面包屑：`设置 / Agents · 团队`，右上角标识 `AGENTS · TEAMS`。

### 2.2 第二级：分区内容页

每个分区都由「页头 + 卡片网格」组成：

```text
设置
└─ Agents / 团队（一级页签）
   └─ 分区内容页（二级）
      ├─ 页头：眉题 / 标题 / 说明 / 数量 / 主操作
      ├─ 卡片网格：Agent 卡片或团队卡片
      ├─ 编辑 Dialog：Agent 640px，团队 560px
      └─ 删除 AlertDialog：460px
```

- Agent 卡片主操作：`编辑`、`删除`。
- 团队卡片主操作：`编辑`、`删除`。
- 删除不进入编辑 Dialog，直接打开独立 AlertDialog；避免把「保存」与「删除」混在同一个底部操作区。
- Dialog 打开时页面进入模态，背景 `rgba(0,0,0,.62)`；Esc 返回列表。

### 2.3 原型评审控件

页签下方有一条「状态」切换条：`加载中 / 空态 / 已配置 / 保存中 / 保存失败`。

- 它只用于在原型里逐态检查，不是产品导航的一部分。
- 当前态使用暖白实底胶囊；其余为透明描边胶囊。
- 右侧提示文字随分区与状态变化，用一句话说明该态的设计意图。

## 3. 数据与关系

### 3.1 Agent

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 显示名；同名（忽略大小写）不允许保存 |
| `desc` | 否 | 一句话描述；卡片上展示 |
| `model` | 否 | 默认模型；空值显示「跟随部署默认」 |
| `tools` | 否 | 工具 id 数组；可以为 0 个 |
| `prompt` | 否 | 系统提示词；可写 inline，也可写 `AGENTS.md` 路径 |
| `avatar` | 否 | 头像 URL；留空使用 identicon |
| `archived` | 否 | 归档标记；卡片显示「已归档」 |

- Agent 只要求名字即可创建；默认模型与工具可以之后再补。
- 默认模型 Select 仅列出已配置 Provider 的模型，按 Provider 分组；第一项是「跟随部署默认」。
- 归档 Agent 不进入队长 / 成员选择器；如果未被团队引用，可以删除。

### 3.2 团队

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 团队名；同名（忽略大小写）不允许保存 |
| `desc` | 否 | 团队描述；卡片上展示 |
| `captainId` | 是 | 队长 Agent id；未选时保存按钮禁用 |
| `memberIds` | 否 | 成员 Agent id 数组，**不含队长**；可以为 0 个 |

- 团队 = 1 位队长 + 0..N 位成员。
- 卡片上的「成员 N 人」只统计 `memberIds`，不含队长。
- 卡片上的 identicon 横排展示的是完整 roster：`[队长, ...成员]`，队长排第一位并带绿色描边。
- roster 最多展示 8 个头像；超过 8 位时追加 `+N`，`N = roster 总数 - 8`。
- 切换队长时：新队长从成员列表移除；旧队长自动变为可选成员。

### 3.3 演示数据

- Agents：10 位（9 位可用，1 位「苏白」已归档且未被团队引用）。
- 团队：3 个。
  - 评审小组：队长许澄，成员林一、沈知。
  - 增长实验：队长顾南，成员林一、唐棠。
  - 交付网络：队长沈知，成员 8 位；完整 roster 9 位，卡片显示 8 个头像 + `+1`。
- 可删除成功示例：苏白（未被引用，删除后 Agents 10 → 9）。
- 409 示例：许澄（评审小组队长）、林一（3 个团队的成员）。

## 4. Agents 分区

### 4.1 页头

- 眉题：`设置 · 03 · Agents`
- 标题：`Agents`
- 说明：`每个 Agent 是一位可被团队引用的成员。默认模型与工具决定它在会话里的能力边界。`

1. identicon 头像：40×40，圆角 9px，底色 `#202020`，5×5 对称方块图案，seed 取 Agent 名。

5. 两个事实徽标：
   - `默认模型` + 模型名；空值显示 `跟随部署默认`。
   - `工具` + 工具数量。
6. 右上角 `编辑`、`删除`；删除使用危险色 hover。

### 4.4 编辑 Dialog（640px）

- 标题：`新建 Agent` / `编辑 Agent`
- 副标题：
  - 新建：`只填名字就能创建；默认模型与工具可以之后再补。`
  - 编辑：`只修改这位 Agent；它所在的团队引用不受影响。`
- 宽度：640px；最大高度 `min(820px, calc(100vh - 48px))`；圆角 14px。
- 头部高 81px；body 内边距 `0 20px 20px`，字段间距 20px；底部高 61px。
- 字段顺序与规格：

| 字段 | 控件 | 高度 | 说明 |
| --- | --- | --- | --- |
| 名字 | input | 40px | 必填；`maxlength=24` |
| 描述 | textarea | 72px | 选填；`maxlength=120` |
| 头像 URL | input + 32px 实时预览 | 40px | 留空用 identicon |

### 4.5 工具 Combobox

- 关闭态：显示已选 chip 或占位 `选择工具（可留空）`；右侧 chevron。
- 打开态：在字段下方展开 listbox，逐项带勾选；多选不自动关闭。
- 已选项 chip：高 26px，胶囊，底色 `#202020`，右侧 22px 圆形 ×。
- 工具全集：文件读写、终端、浏览器、网络搜索、代码执行、文档、日历、记忆、CRM。
- Esc 先关闭菜单并把焦点还给 chevron；再按 Esc 才关闭 Dialog。
- 菜单打开时按钮 `aria-expanded="true"`，chevron 旋转 180°。

## 5. 团队分区

### 5.1 页头

- 眉题：`设置 · 04 · 团队`
- 标题：`团队`
- 说明：`团队由一位队长和若干成员组成。队长决定最终结论，成员提供各自的专长。`
- 数量：`3 个团队 · 10 位 Agent`（空态为 `0 个团队`）
- 主操作：`新建团队`

### 5.2 团队卡片

每张卡片固定展示：

1. 队徽：40×40，圆角 10px，盾形描边 + 3 条 seed 决定宽度的横条；底色 `#202020`。
2. 团队名：15px / 600。
3. 描述：12px / 1.65。
4. **独立一行** `队长：<Agent 名>`：皇冠图标 + 名字 + 绿色「队长」徽标。
5. 底部左侧 `成员 N 人`（不含队长）。
6. 底部右侧 identicon 横排：22×22，圆角 6px，重叠 -6px；队长带绿色描边；超过 8 位显示 `+N`。

卡片规格：与 Agent 卡片一致——最小高度 172px、内边距 16px、圆角 10px、2 列 / 1 列响应式。

### 5.3 空态

```text
[shield 图标]
还没有团队
团队必须先有一位队长。先创建 Agent，再把合适的成员编进团队。
需要先有 Agent；团队至少要有一位队长。
[新建团队]
```

- 没有可用 Agent 时，「新建团队」按钮禁用；有可用 Agent 时可用。
- 空态页头数量为 `0 个团队`。

### 5.4 编辑 Dialog（560px）

- 标题：`新建团队` / `编辑团队`
- 副标题：
  - 新建：`先选队长，再挑成员；队长自动计入团队。`
  - 编辑：`更换队长会把新队长移出成员列表；旧队长回到可选成员。`
- 宽度：560px；最大高度 820px；圆角 14px。
- 字段：

| 字段 | 控件 | 高度 | 说明 |
| --- | --- | --- | --- |
| 团队名 | input | 40px | 必填；`maxlength=24` |
| 描述 | textarea | 72px | 选填；`maxlength=120` |
| 队长 | select | 40px | 必填；只列可用 Agent |
| 成员 | 多选 Combobox | 字段 40px | 不含队长；队长项禁用 |

- 队长未选时：
  - 保存按钮 `disabled`。
  - 字段下方显示警告色提示：`团队必须有队长。`
  - 若按 Enter 提交，则显示同文案的字段错误，并把焦点移到队长 Select。
- 队长提示（已选时）：`队长决定最终结论，并自动计入团队。`
- 成员提示：`成员不含队长；队长项不可移除，换队长后才能调整。`
- 底部左侧说明：`团队名与队长为必填项。`
- 底部操作：`取消` + `保存`。

### 5.5 成员 Combobox

- 关闭态：已选成员 chip 或占位 `选择成员（可留空）`。
- 打开态：第一项固定为当前队长，禁用、带勾选、右侧标注 `（队长，不可移除）`；其余可用 Agent 逐项多选。
- 队长项不可点击、不可聚焦；其它成员项与工具项行为一致。
- 成员可以为 0；只有队长也可以保存。
- 切换队长后立即重渲染：新队长变为禁用项，旧队长回到可选列表。

## 6. 五态矩阵

> 两个分区各自拥有独立的五态。切页签不会丢失另一侧的选择。  
> 「保存中 / 保存失败」会直接打开该分区第一位实体的编辑 Dialog；关闭后回到该分区的「已配置」或「空态」。

### 6.1 Agents

| 状态 | 页面表现 | 关键文案 / 数值 |
| --- | --- | --- |
| 加载中 | 4 张骨架卡；页头数量 `读取中…`；主按钮禁用 | 提示：`读取 Agent 清单与团队引用；骨架按最终卡片高度预留。` |
| 空态 | 单张空态卡；页头数量 `0 位 Agent` | 标题：`还没有 Agent，创建一个`；说明：`只填名字就能创建；默认模型与工具可以之后再加。团队至少要有一位队长，所以先建 Agent。` |
| 已配置 | 10 张 Agent 卡片；2 列 | 数量：`10 位 Agent · 1 已归档`；提示：`Agent 卡片带默认模型与工具数；被团队引用的成员在删除时会被拦下。` |
| 保存中 | 打开「编辑 Agent」；字段与关闭 / 取消防作；保存按钮 spinner；`aria-busy="true"` | 1.4s 后自动完成；toast `已保存`；提示：`保存时锁定字段并保留 Dialog；写入完成前不关闭。` |
| 保存失败 | 打开「编辑 Agent」；标题旁「保存失败」危险徽标；名称预填冲突值 `林一`；名称字段报错 | 汇总：`保存失败：名称已被占用`；字段：`已有同名 Agent，请换一个名称。`；提示：`失败原因贴近字段，输入全部保留；重试无需重填。` |

### 6.2 团队

| 状态 | 页面表现 | 关键文案 / 数值 |
| --- | --- | --- |
| 加载中 | 2 张骨架卡；页头数量 `读取中…`；主按钮禁用 | 提示：`读取团队、队长与成员引用。` |
| 空态 | 单张空态卡；页头数量 `0 个团队` | 标题：`还没有团队`；说明：`团队必须先有一位队长。先创建 Agent，再把合适的成员编进团队。`；补充：`需要先有 Agent；团队至少要有一位队长。` |
| 已配置 | 3 张团队卡片；2 列；第三张 roster 显示 `+1` | 数量：`3 个团队 · 10 位 Agent`；提示：`队长单独成行；成员 identicon 横排，超过 8 位折叠为 +N。` |
| 保存中 | 打开「编辑团队」；字段与关闭 / 取消防作；保存 spinner | 1.4s 后自动完成；toast `已保存`；提示：`保存团队时锁定队长与成员选择。` |
| 保存失败 | 打开「编辑团队」；「保存失败」危险徽标；名称预填冲突值 `增长实验` | 汇总：`保存失败：团队名已被占用`；字段：`已有同名团队，请换一个名称。`；提示：`队长不可用时保留已选成员，换一位队长即可重试。` |

### 6.3 状态切换行为

- `加载中`：不打开 Dialog；渲染骨架；主操作禁用。
- `空态`：不打开 Dialog；只显示创建引导；页头数量归零。
- `已配置`：正常网格；主操作可用。
- `保存中`：打开第一位实体；保存按钮显示 spinner `保存中…`；所有字段、关闭按钮、取消按钮禁用；Esc 无效；1.4s 后自动关闭并 toast `已保存`。
- `保存失败`：打开第一位实体；自动填入一个冲突名称；标题旁危险徽标；汇总 alert + 字段错误；焦点落在名称输入；全部输入保留；改名字后错误清除，可重新保存。
- 关闭失败态后，该分区回到 `已配置`（或数据为空时的 `空态`）。

## 8. 徽标三色与对比度（实测）

测量口径：Chrome 计算后的前景色与背景色，按 WCAG 2.x 相对亮度计算；背景统一取徽标实底 `#202020`（`rgb(32,32,32)`）。

| 徽标 | 前景色 | 背景 | 对比度 | 用途 |
| --- | --- | --- | --- | --- |
| 正向 | `#8ED3AC` | `#202020` | **9.36:1** | 队长徽标、成功状态 |
| 注意 | `#E6B76A` | `#202020` | **8.80:1** | 已归档、未选队长提示 |
| 错误 | `#F08C7C` | `#202020` | **6.79:1** | 保存失败、删除 |
| 主文字 | `#EDE9E1` | `#202020` | **13.46:1** | 事实值、徽标主文字 |
| 次文字 | `#B4AFA5` | `#202020` | **7.46:1** | 次说明 |
| 辅助文字 | `#8C887F` | `#202020` | **4.61:1** | 事实标签（11px，AA 正文通过） |

- 三色均高于 WCAG AA 正文 4.5:1；最低的辅助文字为 4.61:1，仅用于 11px 标签，仍满足 AA。
- 徽标不只靠颜色传达状态：均带圆点 + 文案。
- 徽标边框使用同色 38% 透明度，不参与文字对比度计算。

## 9. 关键规则与文案

### 9.1 队长必选

- 团队 Dialog 未选队长时，`保存` 按钮保持 `disabled`。
- 字段下方常驻警告色提示：`团队必须有队长。`
- 若在团队名输入框按 Enter，仍会触发保存校验：
  - 字段错误：`团队必须有队长。`
  - 焦点移动到队长 Select。
- 队长 Select 只列出未归档 Agent；没有可用 Agent 时 Select 禁用。

### 9.2 队长不可移除

- 成员 Combobox 第一项固定为当前队长：
  - 禁用；
  - 带勾选；
  - 文案右侧标 `（队长，不可移除）`。
- 成员 chip 中永远不含队长。
- 更换队长：
  - 新队长立即从成员列表移除；
  - 旧队长回到成员可选列表；
  - 保存后卡片队长行同步更新。
- 团队卡片队长行文案：`队长：<Agent 名>`，并显示绿色「队长」徽标。

### 9.3 被引用删除：409 失败

删除顺序：卡片「删除」→ AlertDialog 二次确认 → 点「删除」→ 服务端引用检查。

被引用时，AlertDialog 原地切换为失败态：

| 项 | 文案 |
| --- | --- |
| 标题 | `无法删除「许澄」` |
| 错误标题 | `这个 Agent 仍被团队引用` |
| 队长原因 | `这个 Agent 是「评审小组」的队长，先从团队里移除。` |
| 成员原因 | `这个 Agent 是「评审小组」「增长实验」等 3 个团队的成员，先从团队里移除。` |
| 操作提示 | `先在团队页更换队长或移除该成员，再回来删除。` |
| 底部操作 | 仅 `关闭` |
| 焦点 | 落到 `关闭` |

- 失败态不删除数据，不关闭 Dialog。
- 未被引用的 Agent（示例：苏白）删除成功，toast：`已删除 Agent「苏白」`。
- 团队删除不需要引用检查，二次确认后直接删除，toast：`已删除团队「<团队名>」`。

### 9.4 头像回退

- 头像 URL 为空：使用 identicon（Agent 名作为 seed，5×5 对称方块）。
- 头像 URL 非空但格式不合法：
  - 字段错误：`头像地址需以 http:// 或 https:// 开头，且不能包含空格。`
- 头像 URL 合法但图片加载失败：`<img onerror>` 移除自身，露出底层 identicon。
- 头像 URL 不写入种子数据；原型默认全部是 identicon。

### 9.5 默认模型

- Agent 的默认模型可以为空。
- 空值在卡片事实徽标中显示 `跟随部署默认`。
- Select 第一项是 `跟随部署默认`，其后按 Provider 分组：
  - Magpie：`Magpie 2 Pro`
  - DeepSeek：`DeepSeek V3.2`、`DeepSeek R1`、`DeepSeek Coder`
  - Anthropic：`Claude Sonnet 4.5`、`Claude Opus 4.1`
- 不显示未配置 Provider 的模型。

### 9.6 归档

- 归档 Agent 卡片显示警告色「已归档」徽标；文字与头像降级。
- 归档 Agent 不出现在队长 / 成员选择器。
- 归档 Agent 若未被团队引用，可以删除。
- 归档不等于删除；团队引用关系仍然存在。

### 9.7 校验汇总

- 单人字段错误：字段下方红色 `.field-error`，带 12px 警告图标。
- 多处错误：Dialog body 顶部红色 alert，文案 `有 N 处需要修正：名字、头像 URL。`
- 冲突错误优先于服务端失败态；失败态保留全部输入。
- 校验失败后焦点落到第一个 `aria-invalid="true"` 控件。

## 10. 三步建一个团队

1. **先在 Agents 页建人。** 点右上或空态的 `新建 Agent`，只填名字，点 `保存`。  
   结果：Agents 列表出现新卡片；默认模型显示 `跟随部署默认`，工具为 0。

保存成功后：团队卡片出现，队长行显示 `队长：<Agent 名>`，底部显示 `成员 N 人` 与 roster；toast `已保存`。

## 11. 键盘与焦点

### 11.1 Tab 顺序

- 页面：`Agents` 页签 → `团队` 页签 → 5 个状态胶囊 → 页头主操作 → 第一张卡片「编辑」→「删除」→ 第二张卡片……
- 一级页签使用 roving tabindex：仅激活页签 `tabindex=0`，另一项 `-1`。
- `←` / `→` 在页签间循环，并立即切换页面。

Agent Dialog：

```text
关闭 → 名字 → 描述 → 头像 URL → 默认模型 → 工具 toggle
→（菜单打开时）工具项…… → 系统提示词 → 取消 → 保存
```

团队 Dialog：

```text
关闭 → 团队名 → 描述 → 队长 → 成员 toggle
→（菜单打开时）队长禁用项不参与 Tab，成员项…… → 取消 → 保存
```

删除 AlertDialog：

```text
取消 → 删除
（409 失败态：仅「关闭」）
```

- Dialog 内 Tab / Shift+Tab 闭环：最后一个可聚焦元素按 Tab 回到第一个；第一个按 Shift+Tab 到最后一个。
- 保存中时，关闭、取消、保存均禁用；焦点停留在 Dialog 内（保存按钮 spinner）。

### 11.2 Esc

| 场景 | 行为 |
| --- | --- |
| Combobox 打开 | 关闭菜单；焦点回到对应 chevron；Dialog 保持打开 |
| Agent / 团队 Dialog | 关闭 Dialog；若有改动，toast `已放弃未保存的修改`；焦点回到来源卡片按钮 |
| 保存中 | 忽略 Esc；Dialog 不关闭 |
| 删除 AlertDialog | 关闭确认；焦点回到来源「删除」按钮 |
| 409 失败态 | 关闭 AlertDialog；不删除数据 |
| 状态保存中预览 | 忽略 Esc，等待自动完成 |

### 11.3 Enter

- 单行输入（名字、头像 URL）按 Enter：触发保存。
- 团队名为空 / 未选队长时按 Enter：进入校验，焦点落到首个错误控件。
- 描述、系统提示词 textarea：Enter 换行，不提交。
- 默认模型、队长 Select：Enter 使用原生选择行为，不提交。
- Combobox 菜单项：Enter 等同点击，切换选中；菜单保持打开。
- 删除 AlertDialog：Enter 触发当前聚焦按钮；初始聚焦在 `取消`，避免误删。

### 11.4 焦点回交

| 操作 | 焦点落点 |
| --- | --- |
| 打开编辑 Dialog | 名字输入框；失败态落在名称错误字段 |
| 关闭 / 取消编辑 | 来源卡片「编辑」；新建则回「新建 Agent / 新建团队」 |
| 保存成功 | 该实体的「编辑」按钮；新建同样落到新卡片 |
| 打开删除确认 | `取消` |
| 取消删除 / Esc | 来源「删除」按钮 |
| 409 失败 | `关闭` |
| 删除成功 | 页头主操作 |
| 切换页签 | 新页签按钮 |
| 选择状态胶囊 | 对应胶囊（保存中 / 失败除外，焦点进入 Dialog） |
