# Keel Harness · 会话面板设计规格

版本 1.1 · 桌面优先 · 深色中文界面 · 配合 `index.html` 阅读

三个面板共用一套令牌与组件：**模型选择器**（会话级模型与思考档位）、**实时语音**（双工通话）、**语音工作台**（系统转写与合成）。本文给出的数值即卡片、弹窗、按钮、间距的实际实现值，与原型逐项一致。

---

## 1. 设计定位

| 项目 | 定义 |
|---|---|
| 产品表面 | AI 员工操作系统的会话界面，桌面优先，1920×1080 可完整预览 |
| 使用者 | 长时间驻留的顾问、运营与工程岗位；高信息密度、低装饰容忍度 |
| 语气 | 仪器式、克制、可核对。信息先于装饰，状态先于动作 |
| 强调色 | 单一强调色 = 暖白 `#F5F1E8`（品牌暖白），只用于选中、焦点、主按钮与「当前」标记 |
| 语义色 | 错误 `#F08C7C`、警告 `#E6B76A`、成功 `#8ED3AC`，仅出现在状态与校验中，不作为强调色使用 |
| 背景 | 中性近黑 `#0A0A0B`，不使用暖米色、渐变、玻璃拟态、霓虹光晕 |
| 字体 | 标题与正文：Avenir Next → Avenir → 苹方；数字与时间戳：SF Mono → JetBrains Mono → Menlo |

### 1.1 视觉方向

近黑中性底 + 暖白强调，靠 1px 描边、字号与留白建立层级，不靠卡片堆叠。所有面板保持同一套 10px 卡片 / 14px 弹窗圆角、同一套 4px 栅格间距、同一套 11–26px 字号阶梯。

## 2. 画布与断点

| 断点 | 行为 |
|---|---|
| ≥1440px | 左侧规范栏 300px（1440 以下为 268px），右侧面板居中；整页最大宽 1560px |
| ≤1100px | 规范栏移到面板上方，两栏变一栏；状态条提示换行到独立一行 |
| ≤860px | 规范栏回到单列；实时语音高度 580px |
| ≤760px | 仅顶栏折成两行：品牌一行，页签独占一行并可横向滚动；保留 44px 触控高度 |
| ≤640px | 进入移动布局：状态胶囊单行排列、超出时横向滚动；弹窗占满宽度、账本改为上下结构、底部控件换行，触控目标 ≥44px |
| ≤480px | 模型行改为上下两段：名称/能力一行，思考档位独占一行（44px 高） |

断点分两层：**760px 只处理顶栏**，避免 641–760px 区间品牌与页签互相挤压；**640px 才收缩内容**，使 641–760px 仍保留桌面的两列账本与 440px 对话框。320px 下页签与状态胶囊分别横向滚动，页面本身不横向溢出。

参考视口：

- 1920×1080：顶栏 64px + 面板状态条约 49px（另留 20px 下间距）+ 内容区 40px 上留白，面板完整可见，无横向滚动。
- 390×844：单列，规范栏、状态条、面板依次向下；弹窗与面板宽度 = 视口 − 32px，状态胶囊 44px 高、可横向滚动。
- 320×900：页签与状态胶囊均可横向滚动，页面 `scrollWidth` 等于 320px（已实测）。

### 3.4 边界与状态的颜色策略

- 文本与小字全部 ≥ 4.5:1；状态点、焦点环、表单边界全部 ≥ 3:1。
- `--line` / `--line-strong` 是明确要求的低对比仪器感描边，只承担分隔与层次，不作为交互控件的唯一识别线索：卡片有底色，选中行有 `--raised` 底，表单有标签、底色、`--line-control` 边界与焦点环。
- 语义色始终与文字同时出现（「连接失败」「已打断」「完成 · 0.9 s」），不依赖颜色单独传达。

## 4. 字号与排版

| 令牌 | 字号 | 行高 | 字重 | 字距 | 使用位置 |
|---|---|---|---|---|---|
| `--fs-26` | 26px | 1.4 | 600 | 0 | 规范栏面板标题 |
| `--fs-20` | 20px | 1.45 | 600 | 0 | 对话框标题、工作台标题 |
| `--fs-16` | 16px | 1.65 | 400 | 0 | 消息气泡、助手正文、账本正文、文本框 |
| `--fs-14` | 14px | 1.6 | 400/500 | 0 | 模型名、音色、次级正文、状态块说明 |
| `--fs-13` | 13px | 1.55 | 400/500 | 0.02em（控件） | 按钮、页签、分段按钮、表单标签说明 |
| `--fs-12` | 12px | 1.55 | 400/500 | 0 | 能力事实、辅助说明、账本说话人、图例 |
| `--fs-11` | 11px | 1.45 | 400/500/600 | 0.04em–0.06em | 时间戳、分组计数、标签、页签序号、底栏注记 |

规则：

- 中文标题一律 `letter-spacing: 0`；负字距只用于拉丁展示字，本规格不使用负字距的中文标题。
- 中文正文行高不低于 1.6；16px 正文固定 1.65，账本 1.7。
- 全大写拉丁文（`KEEL HARNESS`、`REALTIME` 形态的标签）必须 `0.06em` 以上，本规格品牌字标使用 `0.18em`。
- 单行正文限制 34–46 个汉字宽度（说明文案 `max-width: 46ch`；规范栏导语 `34ch`）。
- 一屏内可见字号不超过 4 档；面板内部只用 11/12/13/14/16/20 六档。

## 6. 动效

| 场景 | 时长 | 缓动 |
|---|---|---|
| 颜色、描边、按钮状态 | 160ms | `cubic-bezier(.2,.8,.2,1)` |
| 面板切换淡入、对话框进入 | 220ms | `cubic-bezier(.2,.8,.2,1)` |
| 对话框进入位移 | 8px 上移 + 缩放 0.995 → 1 | 220ms |
| 会话场景对比度（关闭弹窗后恢复） | 320ms | `cubic-bezier(.2,.8,.2,1)` |
| 活动状态点外环 | 1.8s / 循环（连接中 1.2s） | 线性缩放 0.7 → 2.6，透明度 0.7 → 0 |
| 波形播放 | 每条 1.15s / 交替，延迟 70ms × 序列 | 缩放 0.45 ↔ 1 |
| 骨架脉冲 | 1.6s / 无限 | 透明度 1 ↔ 0.5 |

- 只动 `transform` 与 `opacity`，不改宽高与位置。
- 出场的过渡时长是入场的 65% 左右；入口 ease-out，出口 ease-in。
- `prefers-reduced-motion: reduce` 下所有动画与过渡降为 0.001ms，保留最终状态。
- 动效只表达状态变化：连接、收音、播放、打断、加载；没有装饰性循环动画。

## 7. 组件规范

### 7.1 按钮层级

| 类型 | 填充 | 文字 | 描边 | 使用 |
|---|---|---|---|---|
| 主按钮 | `#F5F1E8` | `#101012`，600 | 无 | 每个视图最多一个 |
| 次按钮 | 透明 | `--ink-2` → hover `--ink-1` | `--line` → hover `--line-strong` | 静音、中断、打开设置 |
| 文字按钮 | 透明 | `--ink-2`，下划线 3px 偏移 | 无 | 从断点继续、恢复默认 |
| 危险按钮 | 透明 | `--danger` | `rgba(240,140,124,.35)` | 结束通话 |
| 禁用 | `--surface-2` | `--ink-3` | `--line` | 未配置时的合成、加载中的说话键 |

同一视口内不出现两个实心主按钮。未配置态的配置入口必须是唯一的实心按钮。

### 7.2 状态展示

- 每个面板顶部有独立状态条，只显示当前面板的 5 个一级状态：**成功 / 加载 / 空态 / 未配置 / 错误**；切换页签时状态条随之切换，不共享。
- 状态胶囊高 30px（≤640px 44px），选中态为暖白实底 + `--accent-ink` 文字，未选中为透明底 + `--ink-2` + 1px 描边；右侧提示行随状态更新，解释该状态的关键取舍。
- 实时语音的成功态内部再分「聆听 / 说话 / 被打断」三个进行子态，通过底部控件进入，不额外增加胶囊数量。
- 通话状态 = 8px 圆点 + 13px 文字标签 + 可选等宽计时；圆点颜色与文字同时变化。
- 活动：实心暖白点 + 1.8s 外环；连接中：空心暖白点 + 脉冲；被打断：琥珀实心点；错误：错误色实心点；空闲：空心灰点。
- 静音等附加事实以独立胶囊呈现（「麦克风已静音」），不替换状态标签。

### 7.3 模型行

- 第一行：5px 当前圆点（仅当前行）+ 模型名 14px/500 + 「当前」标签（11px、1px 暖白描边）。
- 第二行：能力事实 12px：`128K 上下文 · 文本 · 工具调用`，用「 · 」分隔，单行优先，最多换两行。
- 右侧：思考档位四段控件，`关 / 低 / 中 / 高`，未选中段 11px `--ink-3`，选中段底色 `#232329` + 暖白文字 + 1px 暖白内描边。
- 档位随模型记忆；点击非当前行的档位会同时选中该模型并应用该档位。
- 当前行底色 `--raised` + `--line-strong` 描边；其他行悬停 `#17171C`。不用左侧彩色竖条。
- 分组标题吸顶：`Provider 名 + 数量徽标`，实底 `#121214`，底边 1px，层级高于行。

### 7.4 工具调用行

`完成图标 + 等宽工具名 + 右对齐状态`；已完成状态用 `--ok`，等待用 `--ink-3`。图标 13px，行高约 30px，嵌在助手卡片内。

### 7.5 波形

- 22 根（消息内）/ 40 根（结果卡），宽 3px，间隔 2px，圆角 2px，高度 4–18px 由固定序列生成。
- 播放中：暖白，逐条 1.15s 缩放动画；停止：`#35353E`。
- 波形是装饰性内容，`aria-hidden`，时间文本承担真实信息。

### 7.6 表单

- 标签常驻在字段上方，12px/600 `--ink-2`，不用输入提示代替标签。
- 文本域 16px/1.7，最小高 118px，底部显示 `字数 / 2000` 与预计时长，两组信息左右分列。
- 下拉 40px 高，自绘 14px 下箭头，选中值 14px。
- 未配置时合成按钮禁用并保持可见，旁边说明原因；配置入口是主按钮。

## 9. 面板二：实时语音

### 9.1 结构

```text
820 × 620 面板
├─ 状态条 56px：状态点 + 状态词 + 计时 | 来源 · 实时事实
├─ 转写区（可滚动，内边距 20px，间距 16px）
│   ├─ 用户右侧气泡（灰底、右下小圆角）

│   └─ 打断标记：居中胶囊「你打断了助手 · 00:18」
└─ 控制条 68px：静音、打断 …（右）结束通话
```

### 9.2 层级决策

1. **三条固定带**：状态条、转写、控件各自占据固定高度；状态变化只替换带内内容，不改变布局高度。
2. **控件按可用性增删**：未配置只有一个主按钮；连接中只有取消；进行中才有静音 / 打断 / 结束。禁用按钮堆叠会让用户以为功能坏了。
3. **打断是事件，不是布局**：插入标记行 + 助手卡片停止态（保留已说文本、标出播放位置、提供「继续这段」），不切换到另一套界面。
4. **双工语义前置**：未配置态直接写明「麦克风持续收音、助手语音边说边播、随时可打断」，并配两条事实卡。

- **非文本对比**：焦点环 16.86:1；状态点 5.42–16.98:1；表单边界 `--line-control` 3.05:1（对输入底）与 3.15:1（对面板）。常规分隔线 1.22:1 为低对比装饰，不作为控件唯一识别依据。
- **焦点**：2px 暖白实线，偏移 2px；模型行、思考档位、页签、分段按钮、播放按钮均可键盘到达；对话框内 Tab 循环，Esc 关闭并把焦点交回「重新打开模型选择器」。
- **键盘**：页签与工作模式支持左右方向键；按住说话支持空格/回车按下、松开结束；模型选择与档位为真实按钮。
- **语义**：对话框 `role="dialog"` + `aria-modal` + 标题关联；状态文字 `aria-live="polite"`；思考档位为 `role="group"` + `aria-pressed`；波形与标记线 `aria-hidden`；图标按钮均有 `aria-label`。
- **非颜色线索**：每个状态点都配状态词；错误、警告、完成都带文字；当前模型同时有圆点、标签与描边。
- **动效**：系统减弱动效时全部动画近似关闭，只保留状态结果。
- **触控**：移动端主要控件 ≥44×44px，相邻控件间距 ≥8px；底部控件与安全区留出 12px 内边距。

## 14. 内容与实现边界

- 原型是单文件静态页面：无外部字体、图片或网络请求；图标为 16px 网格内联 SVG，线条 1.4px，圆角端点。
- 每个面板顶部的「状态」条属于规格审阅工具，不属于产品界面；产品内不存在该控件。它只显示当前页签的 5 个状态，切换页签时整条切换。
- 数据为真实感的中文业务内容（客户回访、CRM 工具调用、传感器固件沟通），不额外标注为测试内容。
- 原型中的「打开模型设置」跳转到模型选择器的未配置态；「重新检测配置」回到模型列表，用于贯通配置前后的状态路径。
- 麦克风采集与音频播放不在浏览器原型能力内：按住说话会追加一条预置的对话记录用来呈现账本增长；播放按钮给出进度与波形状态，不发声。
