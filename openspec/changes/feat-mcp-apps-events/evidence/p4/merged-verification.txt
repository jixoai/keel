## 1. 结构断言（实际是什么）

复核注记曾写「架构测试断言 mcphost 不 import kernel/store」。实际不是：

- `internal/architecture/mcp_events_isolation_test.go`
  - `TestMCPHostDoesNotImportProductSSE`：断言 `internal/mcphost` 的**传递 import 图**不含
    `internal/httpapi`、`internal/agentapi`（MCP 订阅面与产品 SSE 不共用 handler/hub）。
  - `TestMCPClientDoesNotImportHostDispatcher`：断言 `internal/mcp` 不 import
    `internal/mcphost` 与 `internal/httpapi`（依赖只指向 host → client）。
- 「账本零新增 kind」的实际断言在 `internal/mcphost/events_test.go` 的
  `TestNotificationStormLeavesLedgerKindSetUnchanged`：对 `kernel.Kinds()` 做前后集合比较，
  并拒绝任何含 `progress`/`mcp.` 的 kind。`internal/mcphost` 没有 kernel/store 写路径，但这是
  代码结构事实，不由 architecture 测试断言。
