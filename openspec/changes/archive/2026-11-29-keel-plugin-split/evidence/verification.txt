What the tests prove
  P1-1  Production Writer.SyncOnce pass 1 projects a ticket into a board task;
        passes 2/3 run Import over that channel, skip the projection by
        board_task_id and the source=superagent label, and keep exactly one
        ticket and one board task. PutBoardLink returns the winner's link when
        a second source id names the same board task.
  P1-2  Import writes no assignment. It stamps WorkerBot and the orchestrator
        owner session, then DispatchTicket runs the guarded Host: one ACTIVE
        assignment with SessionID != nil and BotID=worker-bot, plus a worker
        launch for the same work item. A repeat dispatch is a no-op; a link
        without an assignment re-runs dispatch.
  P1-3  board Start failure -> board FAILED, superagent PENDING
        ("waiting for: board"), Build not called, product gate nil. Disabled
        board -> the same PENDING. Success -> Build sees the published board
        service, plugin ACTIVE, product gate returns the supervisor.
  P2-2  ready.go lists plugin_state/plugin_config/plugin_dependency and the
        superagent_* tables; TestReadyCoversPluginOwnedSchema pins the list.
  P2-3  Non-test core-store Go files may not name superagent/board-log tables
        (ready.go and rls.go are listings); importer.go must call
        GetBoardLinkByTask and projectedBoardTask.
  P2-4  `mirror.readOnly`/`mirror.bridge` and the bridge answer action are gone
        from the wire, store, fixtures and task UI; a stale `answer` token is
        ignored (board data test).
  P2-6  A non-empty legacy collab_*/board_links table fails Migrate with its
        row count and an export/rebuild instruction; empty leftovers drop.
  P2-7  pluginstore has no install writer; the core store/harnessext owns the
        plugins inventory row.
  P2-8  Unload then Load starts both plugins again; the superagent Stop callback
        runs twice and its capability is removed after each unload.
  P2-9  Only waiting/ready/claimed/blocked board tasks are imported;
        completed/canceled/archived are skipped.
