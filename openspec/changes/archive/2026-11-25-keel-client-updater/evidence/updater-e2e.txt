5. Windows 路径（交叉编译 + 脚本断言；未在真实 Windows 运行）
-----------------------------------------------------------
$ GOOS=windows GOARCH=amd64 go build ./cmd/keel
WINDOWS-BUILD-OK
$ go test ./cmd/keel -run TestWindowsUpdateScript -v
--- PASS: TestWindowsUpdateScript

helper 脚本语义：
- 等待 updater PID 退出；
- 等待所有同名 keel.exe 退出（有界 60 次，每次约 2s）；
- move /Y 重试 12 次（杀毒/文件锁抖动）；
- 失败写 <exe>.update.log；成功后 start 新 exe 并自删。
边界：本机无 Windows，未做运行期实测。

7. 视觉
-------
四张下载页 Update/升级段截图（EN/ZH × 1440/390）：

由 vision 子代理独立判读；报告：.agents/reports/keel/updater-2026-11-25/report.html

已知边界：
- Windows 更新器只有交叉编译与脚本单测，没有真实 Windows 运行证据。
- GitHub Release 页面解析依赖 github.com 的 302 跳转；自建 manifest 可绕过。
- 校验和与归档来自同一发布账号，只防传输损坏，不防账号失陷；后续可加签名 manifest。
- 0.3.1 及更早二进制没有 update 子命令，第一次升级需手动下载。
