Review items → fixes:

P1-A CSP wildcard TLD (internal/mcphost/csp.go)
- Host is validated by hostname; trailing dots are stripped first (so `*.com.`
  cannot bypass the label rule); a wildcard must keep at least two labels and
  may not name loopback (`*.localhost`) or an IP (`*.127.0.0.1`).
  `https://*.example.com` stays accepted and is normalized to lower case.
- Tests: TestBuildCSPWildcardRequiresTwoLabels (rejects *.com, *.net, *.localhost,
  *.com., *.x, *, *.127.0.0.1; accepts *.example.com and normalizes *.Example.com.).

P1-B unbounded `_meta` and diagnostics
- internal/mcp/resources.go: AppResourceMetaMaxBytes = 64 KiB on
  len(content.Meta)+len(result.Meta); over the bound the whole `_meta` is ignored
  and AppResource.Diagnostics carries one "_meta ignored" note; the document
  remains usable. Tests with a literal 16 MiB `_meta` and with two halves whose
  sum crosses the bound (app_meta_test.go).
- internal/mcphost/diagnostics.go (new): diagCollector (32 messages + "…N more
  dropped", formatting skipped once full) and boundDiagnostics for combined lists.
  parseResourceMeta / parseCSPBlock / parsePermissions / parseStringList /
  sanitizeCSPDomains all use it; parseStringList also caps inspected entries at
  64, and sanitizeCSPDomains stops scanning once the diagnostic budget is spent
  (previously an all-invalid list never broke). The registry applies one final
  per-app budget across metadata + CSP + reader diagnostics.
- Tests: 16 MiB meta; 5000 unknown keys → ≤32+1; 1000-entry domain list capped;
  5000 invalid CSP entries → ≤32+1; diagCollector with 2,000,000 messages → 33
  outputs (counters only, no retained strings).

P2-1 loopback/private CSP domains
- Default policy rejects 127/8, ::1, 10/8, 172.16/12, 192.168/16, 169.254/16,
  localhost/*.localhost and all-numeric IPv4 forms. `CSPOptions.AllowPrivateDomains`
  (registry: Options.AllowPrivateDomains) opens it for dev fixtures; off by default.
- Tests: TestBuildCSPPrivateDomains (negative default, positive with the option,
  numeric host still refused, public origin accepted under both).

P2-2 tenant-aware caching of the view response
- `Vary: X-Tenant-ID` on the 200 document response (immutable cache semantics
  kept).
- Test: TestMCPAppViewSecurityHeaders asserts the header.

P2-4 keepPrevious unprotect window
- resolve() now stores and protects the new document first; only then unpins the
  previous version. A failed put (cache full) leaves the previous version pinned
  and served; a failed re-fetch keeps the previous version as before.
- Tests: TestRegistryKeepsPreviousVersionWhenCacheIsFull (cache-full content
  change keeps serving the old hash with a `cache` diagnostic) and
  TestRegistryContentChangeReclaimsCache (superseded version becomes evictable
  and is reclaimed by the next insert).

P2-6 port range

  Test: TestBuildCSPPortRange.

P2-3 zero-tenant ops semantics
