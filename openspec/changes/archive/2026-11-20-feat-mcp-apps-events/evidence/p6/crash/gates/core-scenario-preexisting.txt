deleted `echo` tool. It now drives the aggregate `mcp` tool, which is part of
the constant v2 surface, against the same real stdio MCP server the mcp-apps
scenario uses. No `echo` shim was added.

What the case does:
  - writes an mcp.json whose server is this binary's `fake-mcp-server`

    so the case kills the previous one first);

    file, then asserts exactly one tool.result and the final text
    "tool mcp returned: plain-ok";
